# Demo Script — IDEIA

**Duração:** 5-8 minutos

## Cena 1 — Abertura (30s)

> Tela: IDEIA com projeto vazio

**Narrador:** "Conheça a IDEIA. A IDE que transforma ideias em sistemas completos. Em vez de escrever código linha por linha, você descreve o que precisa — e a IDEIA faz o resto."

## Cena 2 — Primeiro Prompt (1min)

> Tela: Chat panel, digitar

**Ação:** Digitar no chat:

```
Crie uma API REST de tarefas com PostgreSQL, autenticação JWT e testes.
```

**Narrador:** "Vou pedir uma API de tarefas com autenticação. Veja como a IDEIA analisa, planeja e executa."

## Cena 3 — Planejamento (1min)

> Tela: Mostrar plano gerado (arquitetura, rotas, modelos)

**Narrador:** "A IDEIA primeiro analisa o pedido e gera um plano de arquitetura. Posso revisar, aprovar ou ajustar antes de gerar código."

## Cena 4 — Geração de Código (1min)

> Tela: Time-lapse da criação dos arquivos

**Narrador:** "Com o plano aprovado, a IDEIA gera todo o código: modelos, rotas, controllers, middlewares, testes. Cobertura completa."

## Cena 5 — Revisão e Testes (1min)

> Tela: Reviewer agent mostrando sugestões, Tester rodando testes

**Narrador:** "O agente Reviewer verifica qualidade e segurança. O agente Tester cria e executa testes automaticamente. Tudo passa pelo policy engine e audit trail."

## Cena 6 — Aprovação e Deploy (30s)

> Tela: Approval flow com 3 níveis, depois deploy

**Narrador:** "Cada etapa requer aprovação configurável. Com tudo verde, a IDEIA pode fazer deploy direto."

## Cena 7 — Dashboard (30s)

> Tela: Dashboard com métricas

**Narrador:** "Métricas em tempo real: cobertura de testes, segurança, compliance LGPD/HIPAA/GDPR, performance."

## Cena 8 — Encerramento (30s)

> Tela: Logo IDEIA

**Narrador:** "IDEIA: descreva sua ideia, nós entregamos o sistema. Disponível para Windows, macOS e Linux. Comece hoje."

## Notas Técnicas

- **Pré-requisitos:** Ollama rodando com llama3, projeto Node.js vazio
- **Fallback:** Se Ollama offline, usar cache de respostas pré-gravadas
- **Música:** Lo-fi instrumental baixo
- **Transições:** Fade suave entre cenas

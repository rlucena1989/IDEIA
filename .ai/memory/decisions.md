# Decisions Log

Este arquivo registra decisões arquiteturais tomadas durante o desenvolvimento,
com o motivo real da escolha (não apenas o "o quê", mas o "por quê").

## Schema de entrada

```yaml
date: ISO_DATE
decision: título curto da decisão
context: qual problema motivou a decisão
alternativesConsidered: [...]
chosen: opção escolhida
reason: motivo da escolha
revisitBy: data ou condição para revisar esta decisão (opcional)
```

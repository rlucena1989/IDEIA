# Definition of Done

Uma feature só está pronta quando possuir:

- contrato ou schema atualizado;
- backend implementado;
- frontend implementado, quando aplicável;
- validações de entrada;
- tratamento de erro;
- estados loading, empty, error e success;
- testes unitários;
- teste e2e para fluxo crítico;
- build passando;
- lint e typecheck passando;
- documentação mínima;
- `.ai/audit/artifact-manifest.json` atualizado.

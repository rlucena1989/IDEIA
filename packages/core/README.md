# AI-Devkit Core

Core SDK do AI-Devkit — interfaces, contratos e tipos compartilhados entre todos os adapters e o CLI principal.

## Funcionalidades

- Interfaces padronizadas para adapters (Adapter, AdapterConfig, AdapterResult)
- Tipos compartilhados entre pacotes do ecossistema
- Contratos de qualidade, segurança e compliance
- Utilitários de diagnóstico e health-check

# Design System

## Objetivo

Centralizar tokens visuais (cores, espacamentos, tipografia) e componentes base reutilizaveis.

## Tokens sugeridos

- Cores: primaria, secundaria, sucesso, erro, aviso, neutra.
- Espacamento: escala de 4px/8px.
- Tipografia: familia, tamanhos, pesos.

## Governanca

Mudancas no design system devem ser documentadas com ADR quando afetarem varios modulos.

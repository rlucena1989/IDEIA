# Guia de Componentes

## Convencoes

- Um componente por arquivo.
- Props tipadas explicitamente.
- Separar componentes de apresentacao (dumb) de containers (smart).

## Checklist ao criar um componente

- [ ] Nome em PascalCase.
- [ ] Props documentadas.
- [ ] Estados de loading/erro/vazio tratados.
- [ ] Acessibilidade basica (labels, aria-*).

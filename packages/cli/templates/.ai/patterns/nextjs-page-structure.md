# Padrão de Página Next.js

Toda página funcional deve conter:

- layout responsivo;
- estado de carregamento;
- estado vazio;
- estado de erro;
- estado de sucesso;
- componentes reutilizáveis;
- integração com contrato/API;
- teste e2e do fluxo principal.

Stack padrão:

- Tailwind CSS;
- shadcn/ui;
- React Hook Form;
- Zod;
- TanStack Query;
- TanStack Table quando houver tabela.

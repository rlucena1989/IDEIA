# Product UX Principles

## Objetivo

Definir princípios para que os sistemas criados com ai-devkit sejam fáceis de aprender, confortáveis e agradáveis de usar.

---

## Princípios

### 1. O usuário deve sempre saber onde está

- Títulos claros.
- Breadcrumbs quando necessário.
- Navegação consistente.
- Estado atual visível.

### 2. O usuário deve sempre saber o que pode fazer

- Ação primária clara.
- Ações secundárias visíveis, mas menos fortes.
- Ações indisponíveis explicadas.

### 3. O usuário deve sempre saber o que aconteceu

- Feedback após ações.
- Confirmações.
- Estados de sucesso e erro.
- Logs/auditoria quando necessário.

### 4. O sistema deve prevenir erros

- Validação clara.
- Confirmações para ações perigosas.
- Defaults seguros.
- Restrições visíveis.

### 5. O sistema deve ajudar na recuperação

- Erros com orientação.
- Repetir tentativa.
- Voltar sem perder dados.
- Suporte contextual.

### 6. O sistema deve ensinar sem atrapalhar

- Empty states educativos.
- Tooltips úteis.
- Onboarding progressivo.
- Microcopy contextual.

### 7. O sistema deve respeitar tempo e atenção

- Menos passos.
- Menos campos.
- Menos ruído.
- Mais automação segura.

### 8. O sistema deve parecer confiável

- Consistência.
- Boas mensagens.
- Performance percebida.
- Segurança explícita quando relevante.

### 9. O sistema deve ser confortável em uso prolongado

- Baixo ruído visual.
- Contraste equilibrado.
- Densidade adequada.
- Padrões previsíveis.
- Fluxos sem esforço desnecessário.

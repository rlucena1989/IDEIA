# Visual Excellence Protocol

## Objetivo

Elevar a qualidade visual dos sistemas gerados pela IA, evitando aparência genérica, amadora ou inconsistente.

---

## Checklist de excelência visual

### Composição

- [ ] Existe hierarquia clara.
- [ ] Espaços em branco são usados intencionalmente.
- [ ] Elementos estão alinhados.
- [ ] Seções têm ritmo visual.
- [ ] A tela tem ponto focal.
- [ ] O layout guia o usuário naturalmente.

### Tipografia

- [ ] Tamanhos seguem escala.
- [ ] Pesos são usados com intenção.
- [ ] Linhas têm comprimento confortável.
- [ ] Textos secundários não competem com primários.
- [ ] Títulos são escaneáveis.

### Cores

- [ ] Paleta é limitada.
- [ ] Cores têm função.
- [ ] Contraste é adequado.
- [ ] Estados são distinguíveis.
- [ ] A interface não depende só de cor.
- [ ] Cores de alerta não são usadas como decoração.

### Profundidade

- [ ] Sombras são discretas.
- [ ] Bordas são consistentes.
- [ ] Superfícies são claras.
- [ ] Elevação comunica hierarquia.

### Movimento

- [ ] Animações são rápidas.
- [ ] Movimento ajuda compreensão.
- [ ] Não há distração.
- [ ] Usuários sensíveis a movimento são considerados.

### Refinamento

- [ ] Empty states são úteis.
- [ ] Erros são elegantes e claros.
- [ ] Loading parece intencional.
- [ ] Ícones têm estilo consistente.
- [ ] CTAs são fáceis de encontrar.
- [ ] A tela parece um produto final.

---

## Regra

Antes de entregar uma UI, a IA deve revisar:

> A tela parece produto final ou apenas protótipo?

Se parecer protótipo, melhorar refinamento visual.

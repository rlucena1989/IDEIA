# E2E Checklist — Feature: Criar um Painel

- [ ] Rota de acesso ao painel protegida por autenticação
- [ ] Estado de loading exibido durante carregamento de métricas
- [ ] Estado de erro exibido em caso de falha de API
- [ ] Estado vazio exibido quando não há dados
- [ ] Dados renderizados corretamente com dados reais de teste
- [ ] Teste E2E automatizado cobrindo o fluxo completo

> Nenhum item pode ser marcado sem execução real do teste E2E correspondente.

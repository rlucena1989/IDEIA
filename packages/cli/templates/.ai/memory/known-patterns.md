# Known Patterns

Padrões de código e arquitetura já validados e aprovados para reuso pelos
agentes de IA neste projeto.

## Schema de entrada

```yaml
name: nome do padrão
appliesTo: [dto, use-case, controller, ...]
example: caminho para arquivo de exemplo real no repositório
rationale: por que este padrão é o preferido
```

## Padrões registrados

Nenhum padrão registrado formalmente até o momento. Ao identificar um padrão
recorrente e aprovado em code review, adicione uma entrada aqui.

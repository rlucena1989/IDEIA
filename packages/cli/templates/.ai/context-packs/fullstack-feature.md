# Context Pack: Feature Fullstack

## Quando usar

Para criar funcionalidade completa de ponta a ponta.

## Contexto mínimo obrigatório

- `.ai/project-manifest.yaml`
- `.ai/quality/definition-of-done.md`
- `.ai/patterns/api-contract-pattern.md`
- `.ai/patterns/nestjs-module-structure.md`

- contrato atualizado;
- backend implementado;
- frontend implementado;
- testes unitários;
- teste e2e;
- estados loading/error/empty/success;
- atualização do artifact manifest;
- execução do quality gate.

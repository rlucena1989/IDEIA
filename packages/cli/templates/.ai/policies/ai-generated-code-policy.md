# AI-Generated Code Policy

## Regras obrigatórias

1. Código gerado por IA deve passar por quality gates antes de merge.
2. IA não pode introduzir caminhos absolutos locais.
3. IA não pode usar comandos destrutivos sem aprovação humana.
4. IA não pode sobrescrever arquivos existentes sem estratégia de backup.
5. IA não pode alterar .env ou arquivos de segredo.

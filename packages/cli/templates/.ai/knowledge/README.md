# AI-DevKit Knowledge Base

Este diretório concentra conhecimento consolidado do projeto para consulta
rápida por agentes de IA, evitando redescoberta repetida de decisões já tomadas.

## Índice de conteúdo

- `ai-ethics.md`: diretrizes de privacidade e não-viés em geração de código.
- `contract-first.md` (se existir): motivação para exigir specs antes de código.
- `comparable-tools.md` (se existir): diferenças entre AI-DevKit e ferramentas como Copilot.

## Regra de manutenção

Qualquer novo aprendizado relevante (decisão técnica, causa raiz de bug recorrente)
deve ser adicionado como um novo arquivo `.md` aqui, referenciado nesta lista.

# Contract-First

## O que é

- Definir DTOs, contratos e APIs antes da implementacao
- Validar todas as entradas com Contract.pre() e todas as saidas com Contract.post()

## Por que usar

- Reduz ambiguidades
- Diminui custo de retrabalho
- Facilita geracao de testes automatizados

## Como aplicar

- Escreva specs de caso de uso antes de codificar
- Gere contratos OpenAPI / Zod quando possivel
- Use documentação para guiar a implementacao

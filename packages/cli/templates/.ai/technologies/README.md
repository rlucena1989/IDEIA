# Tecnologias do Projeto

Este diretório descreve como o projeto cresce de um pequeno MVP até um sistema corporativo/industrial complexo.

## Níveis de maturidade

- MVP/PoC: TypeScript, Node.js, Jest, OpenAPI, Docker, ESLint
- Plataforma de médio porte: observabilidade, CI/CD, Docker Compose/Kubernetes, contrato API, testes de integração, monitoramento
- Empresa/Industrial: DDD, microsserviços, event sourcing, CQRS, malha de serviço, GitOps, IoT/edge, zero-trust, compliance, governança de IA

## Como usar

- Atualize este documento quando a stack mudar
- Referencie este documento para qualquer modelo de IA começar de novo em qualquer estágio

## Importante

- Mantenha ".ai/context/ai-handoff.md" e ".ai/memory/session-log.md" sincronizados
- Mantenha ".ai/project-manifest.yaml" com a stack atual
- Mantenha ".ai/technologies/enterprise-stack.md" atualizada para casos de uso avançados
- Use ".ai/checklists/release-readiness-checklist.md" antes de entregar para producao

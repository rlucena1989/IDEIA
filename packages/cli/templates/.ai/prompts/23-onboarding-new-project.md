# Onboarding: Novo Projeto

Voce esta iniciando um projeto do zero com esta estrutura.

## Regra de Proatividade (NOVO)

Ao iniciar um novo projeto, se arquivos base de definicao (.ai/product/vision.md, .ai/project-manifest.yaml, .ai/context/ai-handoff.md, users-and-personas.md, business-goals.md) estiverem vazios ou em formato de template, voce DEVE ser proativo e formular perguntas para o usuario preencher esses documentos ANTES de codificar.

# @ideia/cli

CLI package for AI-Devkit — provides all commands for governance, compliance, code generation, and project management.

## Commands

- `scorecard` — Maturity scorecard (v10, 14 categories, 84 items)
- `optimize` — Decision Optimization Layer
- `generate` — Code generation
- `review` — Adversarial code review
- `audit` — Governance audit
- `verify` — Quality gates
- And 50+ additional commands

## Usage

```bash
ai-devkit <command> [options]
```

## Installation

```bash
npm install @ideia/cli
```
